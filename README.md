# Петелька

Готовий статичний багатосторінковий сайт про в’язання українською мовою.

## Сторінки

- `index.html` — головна;
- `dovidnyk.html` — техніки, пряжа, таблиця розмірів і фільтр складності;
- `praktyka.html` — майстер-класи, поради, помилки, догляд і сезонні ідеї;
- `servisy.html` — калькулятор пряжі, конвертер та інтерактивний тест;
- `natkhnennia.html` — галерея й бібліотека схем;
- `pro-avtorku.html`, `faq.html`, `spilnota.html` — додаткові сторінки.

## Запуск

Відкрийте `index.html` у браузері. Для публікації на GitHub Pages завантажте весь вміст цієї папки в корінь репозиторію та активуйте Pages для гілки `main`.

Форма спільноти є демонстраційною і не надсилає дані на сервер. Для реального приймання повідомлень її потрібно під’єднати до поштового сервісу або власного бекенду.
